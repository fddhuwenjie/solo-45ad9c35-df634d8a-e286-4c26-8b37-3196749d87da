# 换版索引校准台（Index Recalibration Workbench）

供图书编辑与索引员在**书稿换版后校准页码索引**的本地 Web 应用。
Python Flask + SQLite + 原生 HTML/CSS/JavaScript，无前端构建步骤，所有处理均在本机完成。

## 运行

```bash
cd index-calibrator
python -m pip install -r requirements.txt   # 仅依赖 Flask
python app.py
# 浏览器打开 http://127.0.0.1:5000
```

数据保存在 `data/calibrator.db`（SQLite）。

## 30 秒演示

1. 打开页面，点击「**载入演示样例**」（养蜂手册：旧版 10 页 → 新版 12 页）。
2. 点击「**▶ 运行匹配**」，顶栏会显示估计出的全书主偏移。
3. 左栏条目带有页码胶囊（旧页 → 新页，高/中/低置信颜色）。内置的换版情形：
   - **换版偏移**：新版多出“第二版前言”，整体后移（如 `Honey Bees 旧1 → 候选新2`）；
   - **段落拆分**：`Anatomy 旧2` 在新版拆到第 3–4 页（候选范围 3-4，原因列“段落拆分”）；
   - **跨页合并**：`Piping 旧5` 的段落与旧第 6 页内容在新版合并到第 7–8 页；
   - `Venom 旧2` 的“蜂毒”句在新版被改写，候选页**条目词消失**，置信降低并给出原因。
4. 点击「**批量接受高置信**」：无歧义的高置信候选一键确认；有歧义原因的自动跳过。
5. 逐条操作：点击任一页码胶囊，在右侧**确认 / 拒绝 / 改绑**；每次决定后同条目其余待确认
   定位号与全部页码范围会重新计算并实时校验。
6. 「问题」标签里预置了：倒置范围（`Smoker 10-9`）、重复参见（Honey→Honey Bees 两次）、
   缺失目标（Royal jelly→不存在的 Jelly production）、主子条目矛盾（Honey 子条目
   varietals 9-10 超出主条目范围）、断裂/越界等；点击问题可跳转到对应条目。
7. **页对照锚点**：在中间并排预览中翻到对应页（如旧版第 1 页 ↔ 新版第 2 页），点击
   「**⚓ 把当前两页设为对照锚点**」并填写备注；右侧「**锚点**」标签可启用、停用、删除
   （均可顶栏「撤销」）。启用的锚点必须单调递增——旧页递增时新页倒退、旧页或新页重复
   占用、超出全书范围都会被拒绝（可选择先存为停用锚点）。系统按锚点建立线性分段映射，
   页面两侧用色条标出所属区间、金色标出锚点页。
8. 锚点面板中「**▶ 按锚点重匹配（先预览）**」：固定锚点页，只重算相邻区间内尚未确认的
   定位号；弹窗先列出受影响条目数和原候选 → 新候选对照，确认后再执行（已确认/已拒绝不动）。
9. 「版本」标签：保存命名版本并可恢复（恢复本身也在撤销栈内，锚点状态随版本保存/恢复）；
   所有人工决定可逐条「↩ 撤销」。
10. 顶栏「导出」：更新后的索引 CSV（待确认项以 `~旧页` 标注）、可打印校样 HTML、
    未决问题报告、**锚点对照表 JSON**（含锚点/备注、映射区间、逐页投影、定位号对照、冲突与漂移）。

## 输入格式

### 分页纯文本（旧版 / 新版）

用独立的页标记行或换页符分页：

```
=== PAGE 1 ===
第一章 标题
正文……

=== PAGE 2 ===
……
```

也支持 `--- 页码 3 ---`、`### PAGE iv ###` 以及 U+000C（form feed，^L）。
没有任何分页标记的文本整体视为第 1 页。

### 索引 CSV

表头大小写不敏感，列名支持常见别名：

| 列 | 别名 | 说明 |
|---|---|---|
| `term` | main | 主条目 |
| `subterm` | sub | 子条目（可空） |
| `kind` | type | `term` / `see` / `seealso`（可写 “see also”） |
| `target` | see, ref | 交叉引用目标条目 |
| `pages` | locators, ranges | `7; 12-14`（分号分隔；支持 7-14、7–14） |

## 匹配方法

- **上下文指纹**：页面/窗口文本的字符 5-gram shingles，比较 Jaccard 与 containment
  （后者对“一页拆两页”更公平）；
- **邻近语句（anchor）**：从旧页范围挑出含条目词的关键句，在新页逐句做指纹 containment，
  并奖励句中条目词命中；
- **标题词**：新页首行标题中的条目实词命中。

候选由三种方法合并：逐页 argmax 映射（`mapped`，可自然表现为拆分/合并）、
全书众数偏移（`offset`）、长度 L±1 的连续窗口滑选（`window`）。
置信度综合范围均分与窗口覆盖率，给出高/中/低，并列出歧义原因：
拆分、合并、偏移不统一、离群偏移、候选胶着、条目词缺失、覆盖过低、跨章。

## 页对照锚点

书稿增删章节或局部重排后，全书单一偏移会让自动候选成片偏离。此时用人工锚点把
「旧版页 ↔ 新版页」逐点钉住：

- **单调性校验**：启用锚点按旧页排序，旧页、新页都必须严格递增；旧页/新页重复占用、
  旧页递增而新页倒退、页码超出全书范围一律拒绝（HTTP 409）。被拒的锚点可先保存为
  停用状态，在锚点面板调整后再启用；停用锚点若与现行启用映射冲突，会列入「冲突与漂移」。
- **分段映射**：相邻锚点之间线性插值，首锚前/末锚后按最近区间斜率外推（单锚时斜率 1）。
  **锚点页始终精确映射到人工指定的新页**；斜率小于 1 的合法压缩区间允许多个旧页
  折叠到同一新页（投影非递减即可，如 旧1→新1、旧10→新5 时旧 10 仍映射到新 5，
  不会被“逐页严格递增”顶开）。匹配时候选块只能落在定位号范围两端相邻锚点所夹的
  新区间内，范围横跨锚点页时还必须覆盖该锚点固定的新页；单页定位号正落在锚点页时，
  锚点候选无条件置顶（`anchor_pinned`）。
- **重匹配**：先在内存副本上试算，返回受影响条目数与原候选→新候选对照，用户确认后才
  写入；**只重算旧范围落在首末锚点之间的待确认定位号**（首锚之前、末锚之后的候选原样
  保留，不删除、不重建；预览中以 `preserved` 计数返回），已确认/已拒绝与锚点页保持不变。
- **快照与导出**：命名版本包含全部锚点（含停用状态与备注）；导出的
  `*_anchors.json` 含锚点、分段区间、逐页投影、定位号对照（投影区间/实际区间/是否同步）
  及冲突（停用锚点冲突、已确认/候选漂移）。

## 实时校验规则

倒置范围、断裂/越界范围、同条目重复或重叠定位号、重复参见、交叉引用目标缺失、
子条目页码超出主条目全部范围（主子矛盾）、跨章节范围（可开关）、
章节起始页奇偶规则（任意/右页 recto/左页 even，章节首页正则可配置）。

## 目录

```
app.py                  Flask 路由（决定/批量/撤销/快照/锚点/重匹配/导入/导出）
core/db.py              SQLite 表结构（含 page_anchors）
core/anchors.py         锚点校验、单调分段映射、定位号区间约束、冲突、JSON 导出
core/importer.py        分页文本与 CSV 解析
core/matcher.py         指纹/邻近语句/标题词匹配、候选与置信度（锚点区间约束）
core/validator.py       实时一致性检查
core/exporter.py        CSV / 打印校样 / 问题报告
core/sample_data.py     内置养蜂手册样例
core/state.py           前端状态组装
static/ templates/      原生 JS 三栏工作台 + 锚点面板与并排页区间标记
tests/                  冒烟 / 回归 / 锚点逻辑 / 锚点 Flask 路由 测试
```
